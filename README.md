# 留鼠看，養活自己

刷到的接案資訊丟進來，整理成一份鼠打開就能看的清單。**不接任何 AI**——資料由你手填，鼠點連結看原始貼文。

- 正式網址：**https://to-safe-tobashi.web.app**
- 不用 API 金鑰、不花錢、沒有額度限制
- 資料只在你自己的 Firebase 專案裡，不會送去任何第三方

---

## 怎麼用

**你**：刷到案子 → 按「＋ 貼新案子」→ 填表 → 收進來。

要填的東西（只有「標題或網址」是必要的，其餘全部可以留空）：

| 欄位 | 說明 |
|---|---|
| 網址 | 原貼文連結，鼠會點進去看細節 |
| 標題 | 清單上顯示的名字。只貼網址沒填標題的話會拿網址當標題 |
| 片型 | 長片／短片／短影音／廣告／其他 |
| 預算 | 照原文寫，「面議」也行 |
| 資訊日期 | 預設今天 |
| 在哪裡看到 | LINE 社群／Threads／FB／其他 |
| 怎麼聯絡 | mail／LINE／私訊，可多選 |
| 聯絡資料 | 對方的信箱或 ID |
| 投遞期限 | 選「無」，或選「有期限」再填日期 |
| 備註 | 其他要注意的 |
| 截圖 | 選填。鼠可以先看截圖再決定要不要點進網址 |

**鼠**：打開就是那張清單。點標題看原貼文，按「投了 ✓」記錄，「套用模板」生一份投遞訊息草稿。

清單可以照 **片型 / 在哪裡看到 / 資訊日期** 分組，有投遞期限的排前面、快到期的更前面。兩邊同時開著也沒問題，改動幾秒內就同步。

---

## 房間與成員

進去要先用 Google 登入，然後輸入房號。

**房號不是密碼。** 每間房有自己的成員名單：

- 房號沒人用過 → 你輸入就成為房主
- 房號已經有人 → 只有名單上的人進得去，其他人看到「這間房不是你的」
- 想邀鼠 → 按「房間成員」→ 填她登入用的那個 Google 信箱

所以房號外流也沒關係，沒被邀請就進不來。別人取一個新房號可以開自己的房，互不干擾。

## 加到手機主畫面

Safari 開網址 → 分享 → 加入主畫面（Chrome 是選單 → 安裝應用程式）。之後開起來沒有網址列，跟 App 一樣。

---

## 備份

按「備份」下載 JSON，「匯入」讀回來。免費版 Firestore 沒有自動備份，定期存一份在雲端硬碟。

⚠️ **備份不含截圖。** 截圖存在 Firestore 的子集合裡，匯出只會帶案子資料。重要的截圖自己留一份原圖。

## 出問題先看這裡

| 症狀 | 通常是 |
|---|---|
| 一直停在「連線中…」 | Firebase 的 Google 登入沒開，或網路斷了 |
| 「這個網域還沒加進 Firebase 的授權網域清單」 | 你用的網址不是 `to-safe-tobashi.web.app`。要用別的網域就得去 Authentication → 設定 → 授權網域 加進去 |
| 「這間房不是你的」 | 房號打錯，或你的信箱不在那間房的成員名單上 |
| 「讀不到資料」 | Firestore 規則沒發布 |
| 鼠進不來 | 名片上加的信箱要是她**登入時用的那個** Google 信箱，不是她平常給客戶的信箱 |
| 截圖存不進去 | 圖太大（上限約 700KB，會自動縮但長截圖可能還是超標），先自己裁一下 |
| 改了程式沒生效 | Service Worker 有快取。`index.html` 和 `sw.js` 已設 no-cache，但手機上還是可以把 App 關掉重開 |

## 給接手的人：技術細節

- 單一 `index.html`，React 走 CDN + 瀏覽器端 Babel 即時編譯。**沒有 build 步驟**，改完直接 deploy。
- 資料結構：
  ```
  rooms/{房號}
    ├─ owner, memberEmails      房主 uid 和成員信箱名單
    ├─ gigs/{id}                案子
    │    └─ media/shot          截圖（dataURL，另存子集合）
    └─ meta/profile             鼠的名片
  ```
- **截圖故意存在子集合**，不放主文件。清單用 `onSnapshot` 即時同步，圖片放主文件的話每次同步都要重新下載全部圖片，手機吃流量。只有展開那一則才載。
- 上傳前用 canvas 縮到 1400px 邊長、JPEG 0.72，壓不到 700KB 會再降三次品質。Firestore 單一文件上限 1MB。
- 刪案子時要自己刪 `media/shot`，**Firestore 不會連帶刪子集合**。
- 部署：`firebase deploy --only hosting`。規則：`firebase deploy --only firestore:rules`。
- `firebase.json` 的 `ignore` 要明確寫 `.git/**`——`**/.*` 只擋開頭是點的檔名，擋不住目錄內容，寫漏會把整個 git 歷史公開出去。
- `worker/` 是舊的 AI 中繼站，**已退役、沒有部署**。留著是為了哪天想接回 AI，細節看那份檔案開頭的註解。
- `DEPLOY-with-claude-code.md` 是當初從零部署的紀錄，描述的是已經拿掉的 AI 版本，只當歷史看。
